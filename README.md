# 调和之夜 · 线上版

3–6 人的隐藏身份卡牌游戏，按你提供的桌游规则制作，可以在电脑浏览器里联机玩。和「同词相见」一样，只有 `server.js` 和 `index.html` 两个文件，零依赖，网页不加载任何境外资源。

## 部署到 Render（和上次一样）

1. 在 GitHub 新建一个仓库，比如 `tiaohe`，然后上传 `server.js`、`index.html`、`package.json`、`README.md` 四个文件。
2. 在 Render 点 **+ New → Web Service**，选择这个仓库：
   - Language：**Node**
   - Build Command：`npm install`
   - Start Command：`node server.js`
   - Instance Type：**Free**
3. 部署完成后，日志里 "Available at your primary URL" 后面就是网址。

注意：这是一个新的网站，网址和「同词相见」不同。Render 免费额度是每个账号每月 750 小时，两个网站共用这些时间。不过网站休眠时不计时，平时偶尔玩完全够用。

## 怎么开一局

1. 房主打开网址，填名字，点「创建房间」，再点「复制邀请」把链接发给朋友。
2. 朋友打开链接，填名字后加入。座位按加入顺序排列，这也是出牌顺序。
3. 3–6 人到齐后，房主选择「标准模式」或「浑沌模式」，然后点「开始游戏」。
4. 轮到你时，点一张手牌，选择「调和 / 质疑 / 特技」打出。质疑和部分特技需要点击上方的玩家作为目标。
5. 查看手牌、调和区、优等生结果等秘密信息时，会弹窗提示，并记录在右侧「只有你能看到」栏里。
6. 所有人都只剩一张手牌时，自动进行三步判定并公布结果。房主可以「回到大厅，再来一局」。

刷新页面或断线后会自动回到房间。游戏进行中不能有新玩家加入。

## 线上版的几个约定

原规则没有写明的地方，我按下面的方式处理了。想改的话告诉我：

- **监禁**：嫌疑值必须大于 0 且为全场最高才会被监禁，并列最高时都被监禁。只收到外星人（-1）或只收到 0 值牌的人不会被监禁；所有人都不大于 0 时，本局没有人被监禁。
- **获胜方式**：同一优先等级满足条件的人一起获胜。例如犯人获胜时共犯也获胜，调和成功时所有学生一起获胜。
- **锁定的玩家**：标准模式下，手牌只剩 1 张的人会被锁定，不能成为班长或大小姐的目标，也不参与新闻部传牌（传给下一位没被锁定的玩家）。如果你打出班长或归宅部后自己只剩 1 张，也无法交换。
- **反面的调和牌**：感染者和归宅部从调和区拿牌时，牌是反面的，只能按位置选。

## 关于画面

卡牌只用阵营配色和文字表示（蓝：学生，红：犯人和共犯，绿：感染者，紫：外星人，金：归宅部），没有使用原版的美术图。网站名字也换成了「调和之夜」。
